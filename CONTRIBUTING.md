# Contributing

Thank you for contributing to Fraoula Data Trust Toolkit.

## Rules
- Keep changes focused.
- Add or update tests when behavior changes.
- Never include customer, proprietary, production, or sensitive data.
- Use synthetic examples only.

## Test locally
```bash
python -m unittest discover -s schema-drift/tests -p "test_*.py" -v
```
